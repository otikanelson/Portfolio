SCENORY

Storyboarding & Art Application

JavaFX MySQL MVC Architecture IntelliJ

Built to help animators and visual storytellers iterate faster. Storyboarding shouldn't feel like a chore—SCENORY provides an fluid canvas to drag panels, sketch scenes, add notes, and zoom into details smoothly.

Key Features

  • Zoom/pan drag & drop canvas
  • Full drawing & shape tools
  • Color palette & eraser support
  • MySQL project persistence
  • Command Pattern MVC architecture
  • Glass-morphism UI
